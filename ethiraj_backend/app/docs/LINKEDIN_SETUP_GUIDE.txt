================================================================================
                     STEP 1: GET ORGANIZATION ID
================================================================================

The Organization ID is the unique number LinkedIn assigns to each Company Page.
You need this to fetch Ethiraj College's company posts.

HOW TO FIND IT:
---------------

Method 1 - From URL:
   1. Go to: https://www.linkedin.com/company/ethiraj-college-for-women/
   2. If the URL shows a number like /company/12345678/ → that's your ID
   3. If URL shows name, use Method 2

Method 2 - From Page Source:
   1. Go to Ethiraj College's LinkedIn Company Page
   2. Right-click → "View Page Source" (Ctrl+U)
   3. Search for "companyId" or "organizationId"
   4. Copy the number value

Method 3 - LinkedIn Admin Center:
   1. If you are an admin of the Ethiraj College LinkedIn page
   2. Go to: https://www.linkedin.com/company/YOUR-COMPANY/admin/
   3. The URL will change to show the company ID

AFTER YOU GET THE ID:
---------------------

1. Open file: .env
2. Find line: LINKEDIN_ORGANIZATION_ID = 
3. Add your ID: LINKEDIN_ORGANIZATION_ID = 12345678
4. Save and restart server

================================================================================
                STEP 2: APPLY FOR MARKETING DEVELOPER PLATFORM
================================================================================

WHY IS THIS NEEDED?
-------------------
LinkedIn's basic API only gives you profile access (name, email, picture).
To fetch POSTS from a Company/Organization page, you need special permission
called "Marketing Developer Platform" access.

HOW TO APPLY:
-------------

1. Go to: https://www.linkedin.com/developers/apps

2. Click on your app (the one you created for Ethiraj College)

3. Go to "Products" tab

4. Find "Marketing Developer Platform"

5. Click "Request Access"

6. Fill out the form:
   - Company: Ethiraj College for Women
   - Use Case: Display organization's LinkedIn posts on college website
   - Website: https://ethiraj.finecons.com
   - Describe: "We want to integrate LinkedIn posts feed on our college 
     website to showcase announcements, achievements, and news updates 
     from our official LinkedIn page to engage students and visitors."

7. Submit and wait for approval (usually 1-7 business days)

WHAT HAPPENS AFTER APPROVAL:
----------------------------
- Your app will have access to "r_organization_social" scope
- API will be able to fetch organization posts
- You may need to re-authenticate (visit /auth/linkedin again)

================================================================================
                    FRONTEND INTEGRATION EXAMPLE
================================================================================

Add this code to your React/Next.js frontend to display LinkedIn posts:

--------------------------------------------------------------------------------

// LinkedInFeed.jsx

import React, { useState, useEffect } from 'react';

const LinkedInFeed = () => {
  const [posts, setPosts] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    fetchPosts();
  }, []);

  const fetchPosts = async () => {
    try {
      const response = await fetch(
        'https://ethiraj.api.finecons.com/api/linkedin/posts?count=5'
      );
      const data = await response.json();
      
      if (data.success) {
        setPosts(data.data);
      } else {
        setError(data.message);
      }
    } catch (err) {
      setError('Failed to load LinkedIn posts');
    } finally {
      setLoading(false);
    }
  };

  if (loading) return <div>Loading LinkedIn posts...</div>;
  if (error) return <div>Error: {error}</div>;

  return (
    <div className="linkedin-feed">
      <h2>Latest from LinkedIn</h2>
      {posts.map((post, index) => (
        <div key={index} className="linkedin-post">
          <p>{post.text?.text || post.commentary || 'Post content'}</p>
          <span>{new Date(post.created?.time).toLocaleDateString()}</span>
        </div>
      ))}
    </div>
  );
};

export default LinkedInFeed;

================================================================================
                         API ENDPOINTS REFERENCE
================================================================================

BASE URL: https://ethiraj.api.finecons.com

| Method | Endpoint                    | Description                    |
|--------|-----------------------------|---------------------------------|
| GET    | /auth/linkedin              | Start OAuth login              |
| GET    | /auth/linkedin/callback     | OAuth callback (automatic)     |
| GET    | /api/linkedin/status        | Check connection status        |
| GET    | /api/linkedin/profile       | Get authenticated user profile |
| GET    | /api/linkedin/posts         | Get LinkedIn posts             |
| DELETE | /api/linkedin/disconnect    | Remove LinkedIn connection     |

Query Parameters for /api/linkedin/posts:
- count: Number of posts to fetch (default: 10, max: 50)

================================================================================
                           TROUBLESHOOTING
================================================================================

PROBLEM: "LinkedIn not connected" error
SOLUTION: Visit /auth/linkedin to authenticate

PROBLEM: Empty posts array returned
SOLUTION: 
  - Check if Marketing Developer Platform is approved
  - Verify Organization ID is correct in .env
  - Make sure authenticated user has admin access to company page

PROBLEM: "Token expired" error
SOLUTION: 
  - The system auto-refreshes tokens
  - If still failing, visit /auth/linkedin to re-authenticate

PROBLEM: Redirect URI mismatch error
SOLUTION:
  - Go to LinkedIn Developer App settings
  - Add exact URL: https://ethiraj.api.finecons.com/auth/linkedin/callback
  - Make sure there are no trailing slashes

PROBLEM: "Insufficient permissions" error
SOLUTION:
  - Apply for Marketing Developer Platform
  - Wait for approval
  - Re-authenticate after approval
