================================================================================
                             BUTTON MODULE APIS
================================================================================

1. ADD BUTTON (Create)
   Method: POST
   Endpoint: /addButton
   Authentication: YES (Required)

   Request Body (JSON):
   {
     "button_name": "string (required)",
     "text": "string (required)",
     "link": "string (required)"
   }

   Response:
   Success: 201 - { "Success": true, "Message": "Button added successfully.", "data": [{ "button_id": 1 }] }
   Error: 400/401/409/500 - { "Success": false, "Message": "Error message" }

---

2. GET ALL BUTTONS
   Method: GET
   Endpoint: /getAllButtons
   Authentication: NO
   Parameters: None

   Response:
   Success: 200 - { "Success": true, "Message": "Buttons retrieved successfully.", "data": [...] }

---

3. GET BUTTONS BY NAME
   Method: POST
   Endpoint: /getAllButtonsByName
   Authentication: NO

   Request Body (JSON):
   {
     "button_name": "string (required)"
   }

   Response:
   Success: 200 - Returns matching buttons by exact button_name

---

4. GET BUTTON BY ID
   Method: GET
   Endpoint: /getButtonById/:button_id
   Authentication: NO

   URL Parameters:
     - button_id: integer (required)

   Response:
   Success: 200 - Returns single button record
   Error: 404 - Button not found

---

5. UPDATE BUTTON
   Method: PUT
   Endpoint: /updateButton/:button_id
   Authentication: NO

   URL Parameters:
     - button_id: integer (required)

   Request Body (JSON) - All fields optional:
   {
     "button_name": "string",
     "text": "string",
     "link": "string"
   }

   Response:
   Success: 200 - { "Success": true, "Message": "Button updated successfully.", "data": [] }

---

6. DELETE BUTTON (Soft Delete)
   Method: DELETE
   Endpoint: /deleteButton/:button_id
   Authentication: NO

   URL Parameters:
     - button_id: integer (required)

   Response:
   Success: 200 - Record marked as deleted (delete_status = 1)

---

7. RESTORE BUTTON
   Method: PATCH
   Endpoint: /restoreButton/restore/:button_id
   Authentication: NO

   URL Parameters:
     - button_id: integer (required)

   Response:
   Success: 200 - Record restored (delete_status = 0)
